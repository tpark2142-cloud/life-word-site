Visitor Tracking Guide

방문자 숫자 / 그래프 확인, Supabase / Google Analytics 확인용 인쇄 안내

1. What Each Tool Is For / 1. 각 도구의 역할

Tool English 한글
Supabase Best for simple homepage visit counts separated into English and Korean. 영문 / 한글 홈페이지 방문 숫자를 간단히 구분해서 보기 좋습니다.
Google Analytics Best for full traffic analysis such as pages, users, devices, countries, and real-time activity. 페이지별 조회, 사용자 수, 기기, 국가, 실시간 활동 등 전체 분석에 좋습니다.
Admin Page Graph Shows English/Korean daily, monthly, and yearly visit bars from Supabase data. Supabase 데이터를 바탕으로 영문/한글 일간, 월간, 연간 그래프를 보여줍니다.

2. Check EN/KR Visit Counts and Graphs / 2. EN/KR 방문 숫자와 그래프 확인

Step English 한글
1 Open the public homepage Open https://www.lifemoment.site. 공개 홈페이지 열기 https://www.lifemoment.site 를 엽니다.
2 Test English View the homepage once in EN. 영문 테스트 홈페이지를 EN 상태로 한 번 봅니다.
3 Test Korean Click KR on the same homepage and refresh once. 한글 테스트 같은 홈페이지에서 KR 를 누르고 새로고침 1번 합니다.
4 Open the admin page Open gallery-admin.html and go to the homepage visit section. 관리자 페이지 열기 gallery-admin.html 을 열고 홈페이지 방문 기록 부분을 봅니다.
5 Check the numbers Confirm English Today and Korean Today are both increasing. 숫자 확인 English Today 와 Korean Today 가 각각 올라가는지 확인합니다.
6 Check the graphs Confirm the daily, monthly, and yearly charts show both English and Korean bars. 그래프 확인 일간, 월간, 연간 그래프에 영문과 한글 막대가 모두 보이는지 확인합니다.
If both numbers stay at 0, first test on the online homepage, not a local file:// page.
숫자가 둘 다 0이면, 먼저 로컬 file:// 파일이 아니라 온라인 홈페이지에서 테스트했는지 확인하세요.

3. Check Supabase Records / 3. Supabase 기록 확인

Step English 한글
1 Open SQL Editor In Supabase, open SQL Editor. SQL Editor 열기 Supabase에서 SQL Editor 를 엽니다.
2 Run this query select id, visited_at, language, page_path, session_key from public.homepage_visits order by visited_at desc limit 20; 이 쿼리 실행 select id, visited_at, language, page_path, session_key from public.homepage_visits order by visited_at desc limit 20;
3 Read the result You should see rows with language = en and language = ko. 결과 읽기 결과에 language = en 과 language = ko 가 보여야 합니다.
4 Check page path A normal online visit should look like / or /index.html, not C:/Users/.... 페이지 경로 확인 정상 온라인 방문이면 / 또는 /index.html 처럼 보이고, C:/Users/... 는 나오지 않아야 합니다.

4. Check Google Analytics / 4. Google Analytics 확인

Step English 한글
1 Open Analytics Go to https://analytics.google.com/. Analytics 열기 https://analytics.google.com/ 로 갑니다.
2 Realtime Open Reports > Realtime to see active users now. 실시간 보기 Reports > Realtime 에서 지금 접속 중인 사용자를 봅니다.
3 Pages and screens Open Reports > Engagement > Pages and screens. 페이지별 보기 Reports > Engagement > Pages and screens 를 엽니다.
4 Read key metrics Focus on Views, Users, and Average engagement time. 핵심 숫자 읽기 Views, Users, Average engagement time 를 중심으로 봅니다.
Google Analytics is best for full traffic analysis. Supabase is best for simple EN/KR homepage counting.
Google Analytics는 전체 트래픽 분석에 좋고, Supabase는 EN/KR 홈페이지 방문 숫자를 간단히 보는 데 좋습니다.

5. Quick Meaning of the Numbers / 5. 숫자 뜻 빠르게 보기

Label English 한글
English Today How many English homepage visits were counted today. 오늘 영문 홈페이지 방문이 몇 번 기록되었는지.
Korean Today How many Korean homepage visits were counted today. 오늘 한글 홈페이지 방문이 몇 번 기록되었는지.
Monthly Visits A month-by-month bar summary. 월별 막대 그래프 요약입니다.
Yearly Visits A year-by-year bar summary. 연도별 막대 그래프 요약입니다.
